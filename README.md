# 🌙🌞 TANGO 🌞🌙

## Cómo se juega

Rellena la cuadrícula de modo que cada celda contenga 🌙 o 🌞.
No puede haber más de dos  o  juntos, ni en vertical ni en horizontal.
  
## Reglas
   
- Cada fila y columna deben tener el mismo número de 🌙 y 🌞 .
- Las celdas separadas por = deben ser del mismo tipo.
- Las celdas separadas por X deben ser de distinto tipo.
- Cada rompecabezas cuenta con una solución correcta y se puede resolver mediante deducción (**NO HAY QUE ADIVINAR**).
